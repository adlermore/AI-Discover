# AI Discover — сайт курса

Интерактивный портал, собранный из документов в корне репозитория
(5 HTML-документов и 6 PDF). Контент не копируется руками: при каждом
`dev`/`build` скрипт заново читает исходные HTML, поэтому после правки
документов достаточно перезапустить сборку.

## Запуск

```bash
cd site
npm install
npm run dev            # http://localhost:4321
npm run build          # полная версия (для ментора) → site/dist
npm run build:student  # версия для ученицы: без материалов ментора
npm run preview        # открыть собранный dist
```

Нужен Node.js 20.3+.

## Страницы

| Адрес | Что там |
|---|---|
| `/` | Обзор: прогресс по 24 занятиям, карта 12 недель, 4 фазы, ритм 90-минутного занятия, матрица «инструмент × занятие», итоговые результаты |
| `/program/` | Индивидуальный учебный план |
| `/course/` | 24 занятия с поиском и фильтрами по фазе и инструменту |
| `/course/1/` … `/course/24/` | Занятие: цель, шкала 90 минут, теория, промпты с кнопкой копирования, задание, отметка «пройдено» |
| `/course/reference/` | Финальный проект и приложения (шаблон промпта, словарь, чек-листы) |
| `/prompts/` | Библиотека из 67 промптов с поиском и копированием |
| `/mentor/guide/`, `/mentor/tips/` | Руководство ментора (hy / ru) и лайфхаки |
| `/docs/` | Библиотека PDF |
| `/docs/<slug>/` | Отдельная страница-просмотрщик для каждого PDF: постраничный просмотр, миниатюры, масштаб, переход к странице, скачивание |

## Режим ментора

Переключатель «Մենթորի ռեժիմ» в шапке показывает заметки «Մենթորին» в
занятиях, раздел «Մենթոր», промпты и PDF ментора. По умолчанию он
выключен, так что во время демонстрации экрана ученица видит только
свою версию. Состояние запоминается в браузере; `?mentor=1` / `?mentor=0`
в адресе включают и выключают его.

`npm run build:student` собирает сайт, где материалов ментора нет вообще:
ни страниц, ни заметок, ни PDF. Эту сборку можно отдавать ученице.

## Как устроено

- `scripts/extract.mjs` разбирает HTML из корня репозитория в
  `src/data/generated/content.json`, копирует PDF в `public/pdf/`, а
  обложки из `covers/` в `public/covers/`. Обе папки в `public/` генерируются
  при сборке и в git не попадают.
- `covers/*.jpg`: превью первых страниц PDF. Если обложки нет, а в системе
  есть `pdftoppm` (poppler), она создаётся автоматически. После обновления
  PDF удалите старую обложку, и она пересоздастся.
- Отметки о пройденных занятиях хранятся в `localStorage` браузера.
- Просмотрщик PDF работает на pdf.js. Страницы рисуются только рядом с
  областью просмотра и выгружаются при удалении от неё, поэтому даже
  71-страничный документ открывается быстро.
- Цвета фаз A–D проверены как категориальная палитра на различимость
  при дальтонизме и на контраст, в светлой и тёмной теме.

## Деплой

Результат сборки — статический сайт в `site/dist`. Для Vercel укажите
Root Directory = `site`. Сборке нужны файлы из корня репозитория, поэтому
опция «Include files outside the Root Directory» должна быть включена
(по умолчанию так и есть). Для публикации в подкаталог:
`BASE=/ai-discover/ npm run build`.
